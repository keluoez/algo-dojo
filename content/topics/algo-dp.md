## 一句话理解

动态规划（DP）的**算法思想**：把一个大问题拆成**有重叠的子问题**，记下子问题答案避免重复计算，再按依赖顺序组合出大问题答案。核心两问：**状态怎么定义、状态之间怎么转移**。

## 学习路径：记忆化搜索 → 递推

先用朴素递归写，发现重复子问题后加缓存（top-down 记忆化），理解依赖关系后再翻译成循环（bottom-up 递推）。

```python
from functools import lru_cache

# 记忆化：爬楼梯
@lru_cache(None)
def climb(n):
    if n <= 2:
        return n
    return climb(n - 1) + climb(n - 2)

# 递推：只依赖前两项，滚动变量 O(1) 空间
def climb_iter(n):
    a, b = 1, 1
    for _ in range(n):
        a, b = b, a + b
    return a
```

## 四档 DP

**1. 线性 DP**：状态沿一个序列推进。

- 爬楼梯：`dp[i] = dp[i-1] + dp[i-2]`。
- 打家劫舍：第 i 家偷不偷，`dp[i] = max(dp[i-1], dp[i-2]+nums[i])`。

**2. 背包问题**：

- 0/1 背包：每件物品选或不选；一维写法容量**倒序**，`dp[j]=max(dp[j], dp[j-w]+v)`。
- 完全背包：物品无限用，容量**正序**。零钱兑换：`dp[amount]=min(dp[amount], dp[amount-coin]+1)`，初始化一个不可达的大值。

**3. 子序列问题（面试最难一档）**：

- LIS 最长递增子序列：`dp[i]` 以 i 结尾的 LIS，检查所有 j<i（O(n²)）；进阶 O(n log n) 的二分牌堆法。
- LCS 最长公共子序列：二维状态，`text1[i-1]==text2[j-1]` 则对角线 +1，否则取上/左较大值。
- 编辑距离：二维。两字符相等无需操作；否则取"删/插/改"三者最小值 +1：

```python
def edit_distance(w1, w2):
    m, n = len(w1), len(w2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(m + 1): dp[i][0] = i
    for j in range(n + 1): dp[0][j] = j
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if w1[i-1] == w2[j-1]:
                dp[i][j] = dp[i-1][j-1]
            else:
                dp[i][j] = 1 + min(dp[i-1][j],    # 删
                                   dp[i][j-1],    # 插
                                   dp[i-1][j-1])  # 改
    return dp[m][n]
```

**4. 路径/网格 DP**：不同路径 `dp[i][j]=dp[i-1][j]+dp[i][j-1]`；带障碍则该格方案数为 0。

## 解题五步法

1. 定义状态（含每个维度的语义，必要时加"以 i 结尾"消除后效性）；
2. 写转移方程；
3. 初始化边界；
4. 确定遍历顺序（保证算当前状态时依赖已就绪，背包注意正/倒序）；
5. 返回哪个状态 + 空间优化（滚动数组）。

## 现实中的典型案例

- **编辑距离**：拼写纠错、模糊搜索、DNA/蛋白质序列比对（你简历里的 NLP 方向必能讲）。
- 零钱/资源组合：营销满减凑单、投资组合约束优化。
- LIS/LCS：版本 diff（Git 文本比对思想）、数据版本合并、基因匹配。
- 路径规划：网格地图最短成本走法、机器人仓储调度。
- 背包：云资源在预算内最大化性能、广告预算分配。

## 易错点

- 状态定义含糊（"dp[i] 是前 i 个"还是"以 i 结尾"）导致转移拼凑。
- 初始值要让后续转移合理：零钱兑换用 `amount+1` 表示不可达，答案仍是它则返回 -1。
- 二维降一维后遍历方向和复用条件必须重新检查。
- 多解计数与最值求法的转移不同（`+` vs `max/min`）。
- 写完用小数据（空、单个、两元素）手算填表验证。
