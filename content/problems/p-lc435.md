solution_code: |
  def erase_overlap_intervals(intervals: list[list[int]]) -> int:
      intervals.sort(key=lambda x: x[1])
      kept = 0
      last_end = float('-inf')
      for start, end in intervals:
          if start >= last_end:
              kept += 1
              last_end = end
      return len(intervals) - kept

给定一个区间集合 `intervals`，返回**使剩余区间互不重叠所需移除区间的最小数量**。区间 [1,2] 和 [2,3] 端点相接，视为不重叠。

**提示**：等价问题是"最多能保留多少个互不重叠区间"；按什么排序能让每一步的选择给后面留出最大空间？

--- 题解 ---

## 思路：经典区间调度（按结束时间贪心）

目标转为求**最多能保留几个**，删除数 = 总数 - 保留数。

按结束时间从小到大排序，依次选取：当前区间 start >= 已选最后区间的 end 就保留。直觉：结束越早，给后续区间留的空间越大，因此每一步都不会让最优解变差（经典交换论证可证）。

## 复杂度

- 时间 O(n log n)：排序主导。
- 空间 O(1)（不计排序开销）。

## 区间问题家族

- 最多不重叠区间 / 最少删除：按 end 排序贪心；
- 用最少箭射爆气球（LC452）：同样按 end，是本题的马甲；
- 合并区间：按 start 排序后顺序合并；
- 插入区间：定位后合并受影响段。

按 end 还是按 start，取决于"要最早结束"还是"要从头铺开"。

## 易错点

- 按 start 排序贪心是错的（一个超长早发区间可能挤掉很多短区间）。
- 相接判定 `>=`，不要写成 `>`。
