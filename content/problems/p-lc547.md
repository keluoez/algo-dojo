solution_code: |
  def find_circle_num(is_connected: list[list[int]]) -> int:
      n = len(is_connected)
      parent = list(range(n))
      size = [1] * n

      def find(x):
          while parent[x] != x:
              parent[x] = parent[parent[x]]
              x = parent[x]
          return x

      def union(a, b):
          ra, rb = find(a), find(b)
          if ra == rb:
              return
          if size[ra] < size[rb]:
              ra, rb = rb, ra
          parent[rb] = ra
          size[ra] += size[rb]

      for i in range(n):
          for j in range(i + 1, n):
              if is_connected[i][j]:
                  union(i, j)

      roots = {find(i) for i in range(n)}
      return len(roots)

有 n 个城市，`is_connected[i][j] = 1` 表示城市 i 和 j 直接相连。**省份**是一组直接或间接相连的城市，组内不含其他不相连的城市。返回矩阵中省份的数量。

**提示**：题目就是求无向图的连通分量个数。并查集每次合并两个连通块，最终根的个数即答案。

--- 题解 ---

## 思路：并查集（Union-Find）

初始每个城市各自一棵单元素树。扫描矩阵上三角（无向对称）：

- is_connected[i][j]=1 → union 两者；
- find 带路径压缩（parent[x]=parent[parent[x]]）；
- union 按 size 把小树挂大树下，避免树变高；
- 最后数互不相同的根：连通分量数 = 省份数。

## DSU 为什么高效

单独看 find 像 O(n)，但路径压缩 + 按大小合并叠加后，均摊每次操作接近 O(α(n))，α 是阿克曼反函数、增长极慢（实际数据中 ≤4），可当常数看。

## 与 LC200 的区别

LC200 网格四连通 → Flood Fill；本题是显式邻接矩阵的无向图 → DSU 最顺手。两类问题都在数连通分量，选型跟"关系怎么给"走。DSU 的另一主场是动态加边场景（Kruskal 最小生成树、在线合并）。

## 复杂度

- 时间 O(n² · α(n))：扫描矩阵主导。
- 空间 O(n)。

## 易错点

- 最终统计前最好再 find 一遍（路径可能未完全压缩到根），直接数 parent[x]==x 也正确——因为只有根才满足 parent[x]==x，这里用 set(find(i)) 双保险。
- 无向图只扫上三角可避免重复 union。
