solution_code: |
  class MyQueue:
      def __init__(self):
          self.in_stack = []
          self.out_stack = []

      def push(self, x):
          self.in_stack.append(x)

      def _transfer(self):
          if not self.out_stack:
              while self.in_stack:
                  self.out_stack.append(self.in_stack.pop())

      def pop(self):
          self._transfer()
          return self.out_stack.pop()

      def peek(self):
          self._transfer()
          return self.out_stack[-1]

      def empty(self):
          return not self.in_stack and not self.out_stack

请仅使用**两个栈**实现一个 FIFO 队列，支持 `push / pop（取并删）/ peek（只取）/ empty`。只能使用栈的标准操作（压入、弹出、栈顶、判空）。

--- 题解 ---

## 思路：入栈进、出栈出，空了才倾倒

- `push` 永远压入 `in_stack`，O(1)。
- `pop/peek` 时若 `out_stack` 为空，把 `in_stack` 元素**整体倾倒**过去——顺序恰好反转，栈顶就是队头。

关键：不要每次入队都倒，空了才倒、一次倒完，每个元素一生最多被倒一次。

## 复杂度

- push O(1)；pop/peek **摊还 O(1)**。
- 空间 O(n)。

## 易错点

- 倾倒条件是 out_stack **为空**，非空时直接出。
- peek 与 pop 都要先触发倾倒。
- empty 要看两个栈都空。
