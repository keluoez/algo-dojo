solution_code: |
  def merge_accounts(accounts):
      parent = {}                     # 邮箱 -> 邮箱（并查集父指针）

      def find(x):
          while parent[x] != x:
              parent[x] = parent[parent[x]]   # 路径减半
              x = parent[x]
          return x

      def union(a, b):
          parent[find(a)] = find(b)

      owner = {}
      for acc in accounts:
          name, emails = acc[0], acc[1:]
          for e in emails:
              parent.setdefault(e, e)
              owner[e] = name
              union(emails[0], e)     # 同一账号内的邮箱全部连通

      groups = {}
      for e in parent:
          groups.setdefault(find(e), []).append(e)

      merged = []
      for emails in groups.values():
          merged.append([owner[emails[0]]] + sorted(emails))
      return merged

用户数据治理团队拿到一批登录账号。同一个人可能注册过多个账号；现在发现：**只要两条账号记录共享任意一个邮箱，它们就是同一个人**（传递成立：A 和 B 共享一个邮箱、B 和 C 共享另一个，则 A、B、C 都是一个人）。

输入 `accounts`，每项是 `[姓名, 邮箱1, 邮箱2, ...]`。请合并属于同一个人的所有记录，返回：

- 每个合并后的账号一项：`[姓名, 邮箱...]`，邮箱**升序**；
- 账号之间的顺序不限（判题按无序比较）。

**提示**："共享即同一个人、还要传递"——这是并查集的经典信号。把邮箱作为节点，"出现在同一条记录里"作为合并条件。

--- 题解 ---

## 思路：邮箱做节点的并查集

对每条账号记录，把它里面所有邮箱 `union` 到一起（全部与第一个邮箱连通）。所有记录处理完后，`find` 相同的邮箱就属于同一个人。

1. **建并查集**：`parent` 是 邮箱 → 邮箱 的映射（字符串做节点，配一个哈希表存父指针）；顺带用 `owner` 记下每个邮箱对应的姓名；
2. **分组**：按 `find(邮箱)` 的根分组；
3. **输出**：每组邮箱排序，姓名取组内任一邮箱的 `owner`（同组必然同名）。

## 复杂度

- 时间 O(A · L · α + ΣE log E)：A 条记录、每条 L 个邮箱做 union（α 近似常数），最后对每组邮箱排序。
- 空间 O(E)：所有不同邮箱。

## 易错点

- **传递合并**不能只做两两比较——链式共享必须靠并查集（或图 BFS/DFS）连通。
- 邮箱是字符串，不能当下标：`parent`/`owner` 都用哈希表。
- 输出邮箱要 `sorted`；`union` 的对象是邮箱本身，不是记录下标（用记录下标也可以，但最后还要邮箱 → 记录的反映射，多绕一步）。
