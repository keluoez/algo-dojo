solution_code: |
  def search(nums: list[int], target: int) -> int:
      left, right = 0, len(nums) - 1
      while left <= right:
          mid = (left + right) // 2
          if nums[mid] == target:
              return mid
          if nums[mid] < target:
              left = mid + 1
          else:
              right = mid - 1
      return -1

给定一个 **n 个元素有序的（升序）整数数组** `nums` 和一个目标值 `target`，存在则返回其下标，否则返回 -1。要求时间复杂度 O(log n)。

**提示**：循环条件用 `<` 还是 `<=`？mid 不命中时左右边界是 `mid` 还是 `mid±1`？把这两个问题想透，二分就不再靠运气。

--- 题解 ---

## 思路：闭区间模板

区间 `[left, right]` 始终表示"答案可能存在的范围"（闭区间）：

- `while left <= right`：left==right 时区间还有一个元素没检查；
- mid 值偏小 → 答案只可能在右侧 → `left = mid + 1`；偏大 → `right = mid - 1`；
- 区间空了（left > right）还没找到，返回 -1。

区间定义、循环条件、边界收缩三者必须自洽：闭区间配 `<=` 和 `mid±1`；若用左闭右开 `[left, right)`，则配 `<` 和 `left=mid+1 / right=mid`。混用是死循环和漏判的根源。

## 复杂度

- 时间 O(log n)，空间 O(1)。

## 易错点

- 用 `(left+right)//2` 在其他语言可能溢出，Python 无碍，可写 `left+(right-left)//2` 作为通用习惯。
- 忘记 +1/-1 导致死循环。
