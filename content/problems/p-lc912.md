solution_code: |
  import random

  def sort_array(nums: list[int]) -> list[int]:
      def quick_sort(left, right):
          if left >= right:
              return
          pivot = nums[random.randint(left, right)]
          i, j = left, right
          while i <= j:
              while nums[i] < pivot:
                  i += 1
              while nums[j] > pivot:
                  j -= 1
              if i <= j:
                  nums[i], nums[j] = nums[j], nums[i]
                  i += 1
                  j -= 1
          quick_sort(left, j)
          quick_sort(i, right)

      quick_sort(0, len(nums) - 1)
      return nums

给定一个整数数组 `nums`，不使用内置 sort，将其升序排列后返回。要求平均时间复杂度 O(n log n)。

**提示**：快排的"划分"动作如何保证一段排好后，小的都在左、大的都在右？随机选 pivot 解决什么问题？

--- 题解 ---

## 思路：快速排序（三路指针划分 + 随机 pivot）

分治：选 pivot，一次划分让"<= pivot 的靠左、>= pivot 的靠右"，再递归两半。

这里用经典的双指针对撞划分：i 从左找 >= pivot，j 从右找 <= pivot，交换后各进一步，直到 i>j，然后递归 `[left,j]` 和 `[i,right]`。

**随机 pivot** 防止数组已有序时固定取端点导致划分极不均匀——那会让快排退化成 O(n²)。

## 复杂度

- 平均 O(n log n)，期望意义；最坏 O(n²)（随机化后概率极低）。
- 空间 O(log n)：递归栈期望深度。
- 不稳定排序。

## 与其他排序对比

归并排序稳定、严格 O(n log n)，但需要 O(n) 辅助空间；堆排序原地 O(n log n) 但常数大、缓存不友好。工程内置排序（Python Timsort）是归并 + 插入的混合体，并针对"部分有序"的真实数据优化。性能实测页可以同场对比它们的实际耗时。

## 易错点

- 递归边界 left>=right 必须正确，否则区间不收敛。
- 划分循环用 `i <= j`，交换后两侧都要推进，否则 pivot 等于元素时可能死循环。
