solution_code: |
  from collections import deque

  def ladder_length(begin_word: str, end_word: str, word_list: list[str]) -> int:
      words = set(word_list)
      if end_word not in words:
          return 0
      queue = deque([(begin_word, 1)])
      while queue:
          word, level = queue.popleft()
          if word == end_word:
              return level
          for i in range(len(word)):
              for code in range(26):
                  ch = chr(ord('a') + code)
                  nxt = word[:i] + ch + word[i + 1:]
                  if nxt in words:
                      words.remove(nxt)
                      queue.append((nxt, level + 1))
      return 0

字典 `word_list` 中有两个单词在**字母顺序与长度都相同时，恰好有一个字母不同**则可以互相转换。给定 begin_word 和 end_word，返回从 begin_word 到 end_word 的**最短转换序列的单词数目**；end_word 不在词典中或无法到达时返回 0。

**提示**："最少步数"指向哪种遍历？与其两两比较单词建图 O(n²)，枚举每个单词的"缺一个字母的通配模式"是否更省？

--- 题解 ---

## 思路：隐式图上的 BFS

每个单词是一个顶点，相差一个字母即有边，问题 = 无权图最短路，BFS 天然按层给出最短距离。

不显式建图：从当前单词逐位置替换 26 个字母，检查结果是否在词典集合中。一个单词长度 L，一层只花 O(26L)，比两两比较 O(n²·L) 省得多（n 很大时还可进一步用 `h*t` 通配模式表预处理邻接）。

访问标记直接用 `words.remove`：入队即从词典删除，保证每个词只处理一次，也防止绕回。

## 复杂度

- 时间 O(n · L · 26) 的量级，L 为单词长度。
- 空间 O(n)。

## 什么时候用 BFS

题目问"最短/最少经过几个状态"，且每一步代价相同（无权），BFS 几乎是条件反射；DFS 找到的第一条路径不保证最短。

## 易错点

- 返回的是**单词个数**不是步数（hit→cog 是 5 个词、4 步）。
- 入队时去重而不是出队时，否则同一单词可能被重复入队。
