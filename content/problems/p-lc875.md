  import math

  def min_eating_speed(piles: list[int], h: int) -> int:
      def hours(speed):
          return sum(math.ceil(p / speed) for p in piles)

      left, right = 1, max(piles)
      while left < right:
          mid = (left + right) // 2
          if hours(mid) <= h:
              right = mid
          else:
              left = mid + 1
      return left

n 堆香蕉，第 i 堆有 `piles[i]` 根。警卫将在 `h` 小时后回来。珂珂每小时选一堆、以速度 k 吃掉其中 min(k, 堆余量) 根（这一堆不够 k 也不会转去另一堆）。求她**在 h 小时内吃完所有香蕉的最小整数速度 k**。

**提示**：这道题数组无序，为什么还能二分？被二分的对象是什么？什么样的 k 构成"可以/不可以"的分界？

--- 题解 ---

## 思路：二分答案

被二分的不是数组，而是**答案速度 k 本身**：

- 判定函数 hours(k)：每堆耗时 ⌈p/k⌉，总耗时关于 k **单调不增**；
- 若 k 能吃完，所有更大的 k 也能吃完 → "可行"是后缀；
- 最小可行速度就是后缀的左边界，用左闭右开/压缩左边界模板二分。

上界取 max(piles)：速度超过最大堆没有任何收益（每堆仍至少 1 小时）；下界为 1。

## 复杂度

- 时间 O(n log M)，M = max(piles)：每次判定 O(n)，共 log M 次。
- 空间 O(1)。

## 什么时候想到"二分答案"

当题目要求"最小化/最大化某个值"，且能写出一个关于该值**单调**的可行性判定时，就把搜索问题转成判定问题。单调性是唯一的入场券。

## 易错点

- ⌈p/k⌉ 用 `(p + k - 1)//k` 或 math.ceil，整除写法会少算时间。
- h 恰好等于 len(piles) 时答案必然是 max(piles)，可作边界自检。
