solution_code: |
  import heapq
  from collections import defaultdict

  def network_delay_time(times: list[list[int]], n: int, k: int) -> int:
      graph = defaultdict(list)
      for u, v, w in times:
          graph[u].append((v, w))

      dist = {k: 0}
      heap = [(0, k)]
      while heap:
          d, u = heapq.heappop(heap)
          if d > dist.get(u, float('inf')):
              continue
          for v, w in graph[u]:
              nd = d + w
              if nd < dist.get(v, float('inf')):
                  dist[v] = nd
                  heapq.heappush(heap, (nd, v))

      return max(dist.values()) if len(dist) == n else -1

有 n 个网络节点（编号 1 到 n），`times[i] = [u, v, w]` 表示信号从 u 经过 w 时间**有向**送达 v。从节点 k 发出一个信号，求**所有节点都收到信号所需的时间**（即 k 到最远节点的最短距离）；若有节点永远收不到，返回 -1。

**提示**：边权非负的单源最短路，为什么 Dijkstra 能贪心——每次从堆里取出的最近未定点，为什么它的距离已经不可能再被改小？

--- 题解 ---

## 思路：Dijkstra + 堆

1. 邻接表存图，dist 记录源点 k 到各点的已知最短距离，起点 0；
2. 最小堆按距离弹出节点；
3. 松弛每条出边：d+w 更小就更新 dist[v] 并入堆；
4. 弹出时若 d 已过期（比记录的 dist 大）则跳过——堆里允许旧条目残留。

全部节点被确定后取 dist 最大值；dist 数量不足 n 说明有不可达节点。

## 贪心正确的关键

边权非负时，未定点中距离最小的 u，任何"绕路经其他点再到 u"的方案距离只会更大（绕的那一段非负），所以 d 已是最终值，可以一次性定死。**负权边破坏这个论证**，那是 Bellman-Ford/SPFA 的场景。

## 复杂度

- 时间 O(E log V)：每条边最多触发一次堆操作。
- 空间 O(V+E)。

## 现实对应

地图导航、网络路由协议（OSPF）、快递时效预估、游戏寻路，底层都是加权最短路。

## 易错点

- 节点编号从 1 开始，dist 用 dict 或大小 n+1。
- 必须跳过过期堆条目，否则会用旧距离错误松弛。
