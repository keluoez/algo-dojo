solution_code: |
  class MinStack:
      def __init__(self):
          self.data = []
          self.mins = []          # 同步栈：data 每个时刻的最小值

      def push(self, val):
          self.data.append(val)
          if self.mins:
              self.mins.append(min(val, self.mins[-1]))
          else:
              self.mins.append(val)

      def pop(self):
          self.mins.pop()
          self.data.pop()           # LeetCode 语义：只移除，不返回

      def top(self):
          return self.data[-1]

      def get_min(self):
          return self.mins[-1]

设计一个栈，在常规 push/pop/top 之外，`get_min()` 要能**在 O(1) 时间**检索栈中最小元素。

**提示**：一个变量记最小值，弹出时它自己可能被删怎么办？需要"历史"。

--- 题解 ---

## 思路：同步最小栈

维护第二个栈 `mins`，每次 push 都同步压入"此刻的最小值"（`min(val, mins[-1])`）；pop 同步弹出。`mins` 栈顶永远是当前最小值。

即使最小值被弹出，其历史记录同时从 mins 消失，新的栈顶就是剩余元素的最小值——这正是单变量方案解决不了的问题。

省空间变体：只有 val ≤ mins 栈顶时才压 mins（弹出时比较两栈顶相等才弹 mins），适合严格区分场景。

## 复杂度

- 每个操作 O(1)；空间 O(n)。

## 易错点

- 两栈必须同进同出（或清楚省空间变体的相等条件）。
- 第一次 push 时 mins 为空，单独处理。
