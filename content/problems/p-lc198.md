solution_code: |
  def rob(nums: list[int]) -> int:
      prev_robbed = 0
      prev_skipped = 0
      for num in nums:
          prev_robbed, prev_skipped = (
              prev_skipped + num,
              max(prev_robbed, prev_skipped),
          )
      return max(prev_robbed, prev_skipped)

沿街有一排房屋，每间房藏有金额 `nums[i]`。若**两间相邻的房屋在同一晚被闯入会报警**，求不触动警报的情况下一夜之内能偷窃到的最高金额。

**提示**：处理到第 i 间房时只有"偷"和"不偷"两种状态，各自由什么前驱转移而来？为什么"不偷 i"的最优值是前一状态两种选择的最大值？

--- 题解 ---

## 思路：两个状态的线性 DP

对每间房维护两个值：

- robbed：考虑到当前房、且**偷当前房**的最优金额 = 上一家不偷 + 当前金额；
- skipped：**不偷当前房**的最优金额 = max(上一家偷, 上一家不偷)——上一家怎样都行。

答案取最后一间两种状态的较大者。代码用两个滚动变量同步更新。

也可写成单状态 f[i]=前 i 间房的最优，转移 `f[i] = max(f[i-1], f[i-2]+nums[i])`；两种写法完全等价，双状态版本在"环形打家劫舍""含手续费的股票"等多约束题上更好扩展。

## 复杂度

- 时间 O(n)，空间 O(1)。

## 易错点

- 更新必须同时进行（右侧引用旧值），先改 robbed 再算 skipped 会用到新值。
- 不偷当前房不等于"上一家必须偷"，所以要取 max。
