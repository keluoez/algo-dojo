  def reverse_list(head):
      prev = None
      cur = head
      while cur is not None:
          nxt = cur.next          # 先保存，否则断链
          cur.next = prev         # 调头
          prev = cur
          cur = nxt
      return prev

给你单链表的头节点 `head`，反转链表并返回新的头节点。

**提示**：迭代版三个指针的更新顺序是核心；也可以尝试递归版——假设 `head.next` 起的部分已经反转好了，你只需做什么？

--- 题解 ---

## 思路（迭代）：逐个调头

维护 `prev`（已反转部分的头）与 `cur`（待处理节点）：

1. 先用 `nxt` 保存 `cur.next`，否则改完指针后半段丢失；
2. `cur.next = prev` 完成当前节点调头；
3. `prev`、`cur` 同时前进。

循环结束 `cur` 为 None，`prev` 即新头。

## 递归版思路

```python
def reverse_list(head):
    if head is None or head.next is None:
        return head
    new_head = reverse_list(head.next)   # 后一段已反转
    head.next.next = head                # 后一段的尾(head.next)指回自己
    head.next = None                     # 自己成为新尾部
    return new_head
```

## 复杂度

- 时间 O(n)：每个节点处理一次。
- 空间 O(1)（迭代）；递归 O(n) 调用栈。

## 易错点

- 忘保存 `cur.next` 导致断链。
- 递归版 `head.next = None` 不写会造环。
