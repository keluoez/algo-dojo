solution_code: |
  def detect_cycle(head):
      slow = fast = head
      while fast is not None and fast.next is not None:
          slow = slow.next
          fast = fast.next.next
          if slow is fast:
              p = head
              while p is not slow:
                  p = p.next
                  slow = slow.next
              return p
      return None

给定链表头节点，若链表有环，返回**入环的第一个节点**；无环返回 `None`。

**提示**：先用快慢指针判环；相遇后，为什么"从头再来一个指针，与慢指针同步前进，相遇点就是入口"？

--- 题解 ---

## 思路：Floyd 判圈两阶段

**阶段一**：slow 每轮 1 步、fast 每轮 2 步。无环 fast 先到 None；有环二者在环内相遇。

**阶段二（为什么是入口）**：设头到入口距离 a，入口到相遇点距离 b，相遇点回入口距离 c。相遇时：

- slow 走了 a+b；fast 走了 a+k(b+c)+b。
- fast 路程是 slow 两倍，可推出 **a = c + (k-1)(b+c)**，即从头走 a 步与 slow 从相遇点绕圈走，必会在入口相遇。

于是从头放指针 p，与 slow 同速，首次相遇即答案。

## 复杂度

- 时间 O(n)：两阶段都是线性的。
- 空间 O(1)。

## 易错点

- 判环循环条件检查 `fast` 与 `fast.next`，顺序不能反。
- 阶段二指针起点是 `head` 不是 `head.next`。
- 返回的是节点而不是下标/布尔值。
