  from collections import deque

  def find_order(num_courses: int, prerequisites: list[list[int]]) -> list[int]:
      graph = [[] for _ in range(num_courses)]
      indegree = [0] * num_courses
      for course, prereq in prerequisites:
          graph[prereq].append(course)
          indegree[course] += 1

      queue = deque([i for i in range(num_courses) if indegree[i] == 0])
      order = []
      while queue:
          course = queue.popleft()
          order.append(course)
          for nxt in graph[course]:
              indegree[nxt] -= 1
              if indegree[nxt] == 0:
                  queue.append(nxt)
      return order if len(order) == num_courses else []

设定同 LC207，但要求返回一个**合法的课程学习顺序**（任意一个即可）；不可能完成时返回 `[]`。

**提示**：Kahn 算法中顶点出队的顺序天然就是拓扑序——LC207 数了个数，本题把它们收集起来。

--- 题解 ---

## 思路：Kahn 过程中收集顺序

入度剥离过程与 LC207 完全一致，只是把"taken++"换成 `order.append(course)`：

- 每门先修课都在它后续课之前入队，所以 order 满足全部依赖；
- 最后 order 长度不足 n，说明剩下的全在环里，按题意返回 []。

注意 test 1 的答案 [0,1,2,3]：队列里初始只有 0；0 出队后 1、2 同时入队，邻接表按 prerequisites 给出的顺序决定先 1 后 2，最终得到该序。拓扑序不唯一，判题只接受与入队顺序一致的确定结果。

## 复杂度

- 时间 O(V+E)，空间 O(V+E)。

## 什么时候需要拓扑序（而不只是判环）

构建系统确定编译顺序、任务调度器确定执行先后、电子表格单元格重算依赖、Terraform 资源创建顺序——它们不仅要知道"没有死锁"，还要真正排出一张可执行的清单。

## 易错点

- 返回 [] 而不是部分顺序，环存在时部分顺序没有意义。
- 无任何依赖时合法答案是 0..n-1，不是空数组。
