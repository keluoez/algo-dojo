solution_code: |
  class _Node:
      def __init__(self, key=0, value=0):
          self.key = key
          self.value = value
          self.prev = None
          self.next = None

  class LRUCache:
      def __init__(self, capacity: int):
          self.capacity = capacity
          self.cache = {}
          self.head = _Node()
          self.tail = _Node()
          self.head.next = self.tail
          self.tail.prev = self.head

      def _remove(self, node):
          node.prev.next = node.next
          node.next.prev = node.prev

      def _add_front(self, node):
          node.prev = self.head
          node.next = self.head.next
          self.head.next.prev = node
          self.head.next = node

      def get(self, key: int) -> int:
          node = self.cache.get(key)
          if node is None:
              return -1
          self._remove(node)
          self._add_front(node)
          return node.value

      def put(self, key: int, value: int) -> None:
          node = self.cache.get(key)
          if node is not None:
              node.value = value
              self._remove(node)
              self._add_front(node)
              return
          if len(self.cache) == self.capacity:
              lru = self.tail.prev
              self._remove(lru)
              del self.cache[lru.key]
          node = _Node(key, value)
          self.cache[key] = node
          self._add_front(node)

---

设计一个 LRU（最近最少使用）缓存结构，支持：

- `get(key)`：key 存在返回其值，否则 -1；
- `put(key, value)`：key 存在则更新；不存在则插入；容量满时**淘汰最久未被访问**的键。

要求两个操作均为 O(1)。

**提示**：O(1) 定位要哈希表；O(1) 维护"新旧顺序"需要什么结构？访问一个键后它应该被挪到哪里？

--- 题解 ---

## 思路：哈希表 + 双向链表（黄金组合）

- cache：key → 链表节点，O(1) 找到目标；
- 双向链表：节点顺序即访问新旧，头 = 最近、尾 = 最久。带哨兵 head/tail，省去空指针讨论。

访问/更新命中：把节点摘下、插到头；插入超容量：删尾节点并同步删 cache。节点里必须存 key——删尾时要知道该删 cache 的哪个键。

## 为什么单靠一种结构不行

只有哈希表：无顺序概念，不知道该淘汰谁；只有链表：查找 O(n)。这是"结构能力互补"的教科书组合，类似的还有堆+哈希（延迟删除）、数组+哈希（O(1) 随机删除）。

## 复杂度

- get / put 均 O(1)。
- 空间 O(capacity)。

## Python 面试补充

生产中可直接用 `collections.OrderedDict`：`move_to_end(key)` 与 `popitem(last=False)` 就是 LRU 原语。但面试官通常要求手写链表证明原理，OrderedDict 可作为一句话的工程注解。

## 易错点

- 摘链/插链共四个指针要全改，漏一个链表就断。
- 更新已存在的 key 也算一次"访问"，要挪到头部。
