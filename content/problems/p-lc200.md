solution_code: |
  def num_islands(grid: list[list[str]]) -> int:
      rows, cols = len(grid), len(grid[0])

      def dfs(r, c):
          if r < 0 or r >= rows or c < 0 or c >= cols or grid[r][c] != '1':
              return
          grid[r][c] = '0'
          dfs(r + 1, c)
          dfs(r - 1, c)
          dfs(r, c + 1)
          dfs(r, c - 1)

      count = 0
      for r in range(rows):
          for c in range(cols):
              if grid[r][c] == '1':
                  count += 1
                  dfs(r, c)
      return count

给定一个由 `'1'`（陆地）和 `'0'`（水）组成的二维网格，计算网格中**岛屿的数量**。岛屿总是被水包围，并且每座岛屿只能由水平/竖直方向上相邻的陆地连接形成。网格四边之外均视为水。

**提示**：从一块陆地出发 DFS，能走到的所有陆地属于同一座岛；如何标记"已归属"避免重复计数？

--- 题解 ---

## 思路：Flood Fill（泛洪染色）

扫描全网格，每遇到一个还没被访问过的 `'1'`，岛屿数 +1，并从它出发 DFS：

- DFS 把**四连通可达的所有陆地**原地改成 `'0'`（相当于染色/已访问）；
- 这样外层扫描再遇到这些格子时不会重复计数。

原地改网格省掉 visited 矩阵；不允许修改输入时改用等大的 visited。

## 网格 DFS 的统一套路

1. 越界或不是目标格 → return（一个守卫条件写完所有边界）；
2. 标记当前格已访问；
3. 向四个（或八个）方向递归。

它本质是在"网格隐式图"上跑 DFS：每个格子是顶点，相邻关系是边。

## 复杂度

- 时间 O(R·C)：每个格子最多访问一次。
- 空间 O(R·C)：最坏全陆地时递归栈深度（也可改显式栈/ BFS 队列规避递归深度问题）。

## 易错点

- 注意元素是字符串 '1'/'0' 不是数字 1/0。
- 递归栈在大网格上可能超 Python 默认深度（1000），可改用迭代 DFS 或调大 recursionlimit。
