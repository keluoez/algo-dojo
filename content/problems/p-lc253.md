solution_code: |
  import heapq

  def min_meeting_rooms(intervals):
      intervals.sort(key=lambda x: x[0])     # 按开始时间排序
      ends = []                              # 小顶堆：各会议室的占用截止时刻
      rooms = 0
      for start, end in intervals:
          if ends and ends[0] <= start:      # 最早结束的会议室已空出
              heapq.heappop(ends)
          heapq.heappush(ends, end)          # 占用一间（复用或新开）
          rooms = max(rooms, len(ends))
      return rooms

公司行政要为一批会议安排会议室：给定 `intervals`（每项为 `[开始, 结束)`，**结束时刻等于下一场的开始时刻时可以共用**同一间），问至少需要多少间会议室。

**提示**：答案 = 所有时刻上"同时在开的会议数"的最大值。把会议按开始时间排序后逐个安排：新会议开始时，最应该问的问题是——"**最早结束**的那间会议室空出来了吗？"

--- 题解 ---

## 思路：开始时间排序 + 结束时间小顶堆

按开始时间逐个处理会议，用小顶堆 `ends` 维护"每间会议室被占用到几点"：

1. 新会议在 `start` 开始，检查堆顶（最早结束的会议室）：`ends[0] <= start` 说明它已空出，弹出让新会议**复用**这间；
2. 把新会议的 `end` 压入堆（复用了旧房间就相当于刷新它的占用截止；没有空房则相当于新开一间）；
3. 堆的大小的历史峰值就是答案。

正确性来自两点：会议按开始时间排序后，只需要跟"最早结束"的房间比较（若它都还没空，其他房间更不可能空）；堆大小恰好等于当前同时在开的会议数，峰值即所需房间数。

另一种等价写法：开始、结束时刻分别排序后双指针扫描（扫描线），喜欢哪个用哪个，复杂度相同。

## 复杂度

- 时间 O(n log n)：排序 + 每场会议一次堆操作。
- 空间 O(n)：堆最坏存全部会议。

## 易错点

- `ends[0] <= start` 是**弹出至多一个**房间（不是 while 全弹）：一场会议只需一间房，多弹会让堆大小低估。
- 首尾相接 `[0,1],[1,2]` 可共用，比较必须带等号。
- 答案是堆大小的**峰值**（`max`），不是处理完后的堆大小（最后一场时堆必然 ≥ 1，但峰值可能早已过去）。
