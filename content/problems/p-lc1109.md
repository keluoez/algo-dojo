solution_code: |
  def corp_flight_bookings(bookings, n):
      diff = [0] * (n + 1)
      for first, last, seats in bookings:
          diff[first - 1] += seats      # 航班编号转下标
          diff[last] -= seats
      answer = []
      cur = 0
      for i in range(n):
          cur += diff[i]
          answer.append(cur)
      return answer

有 n 个航班编号 1..n。`bookings[i] = [first, last, seats]` 表示从 first 到 last（含两端）每个航班都被预订 seats 个座位。返回长度 n 的数组，第 i 项是第 i+1 个航班的总预订座位数。

**提示**：m 条区间记录，朴素处理是 O(m·n)；每个操作本质是"区间加"，差分数组怎么把它压成 O(m+n)？

--- 题解 ---

## 思路：差分数组的直接套用

建立长度 n+1 的 `diff`。一条"区间 [first, last] 加 seats"只改两个点：

- `diff[first-1] += seats`（编号转下标）
- `diff[last] -= seats`（右边界外侧）

全部记录处理完，前缀和扫描一遍，即得每个航班的座位数。

## 复杂度

- 时间 O(m+n)：每条记录 O(1)，最后还原 O(n)。
- 空间 O(n)。
- 朴素逐航班累加是 O(m·n)，预订区间长时差距明显。

## 易错点

- 航班号从 1 开始：左端 -1，右端 `last` 不减 1（恰为右外侧下标）。
- diff 长度取 n+1，last 可能等于 n。
