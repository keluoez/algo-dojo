solution_code: |
  def copy_random_list(head):
      if head is None:
          return None

      # 第一轮：在每个原节点旁边挂上克隆节点
      cur = head
      while cur is not None:
          clone = Node(cur.val)
          clone.next = cur.next
          cur.next = clone
          cur = clone.next

      # 第二轮：克隆节点的 random 指向原 random 旁边的克隆
      cur = head
      while cur is not None:
          if cur.random is not None:
              cur.next.random = cur.random.next
          cur = cur.next.next

      # 第三轮：拆成两条链表
      cur = head
      new_head = head.next
      while cur is not None:
          clone = cur.next
          cur.next = clone.next
          if clone.next is not None:
              clone.next = clone.next.next
          cur = cur.next
      return new_head

链表节点除了 `next` 外还有一个 `random` 指针，可能指向任意节点或 `None`。请对链表做**深拷贝**，返回新链表的头节点。

**提示**：难点是克隆 random 时，目标克隆节点可能还没创建。经典两种方案：哈希映射（原节点→克隆节点），或"原地穿插后拆分"。

--- 题解 ---

## 思路一：哈希映射（推荐先写，直觉清晰）

```python
def copy_random_list(head):
    if head is None:
        return None
    clones = {}
    cur = head
    while cur is not None:                 # 先把所有克隆节点建好
        clones[id(cur)] = Node(cur.val)
        cur = cur.next
    cur = head
    while cur is not None:                 # 再统一连 next / random
        clone = clones[id(cur)]
        if cur.next:
            clone.next = clones[id(cur.next)]
        if cur.random:
            clone.random = clones[id(cur.random)]
        cur = cur.next
    return clones[id(head)]
```

## 思路二：原地穿插（O(1) 额外空间）

三轮操作（参考实现即此法）：

1. 每个原节点后插入自己的克隆（A → A' → B → B'）；
2. 利用穿插关系连 random：`cur.next.random = cur.random.next`；
3. 把两条链拆开，同时恢复原链表。

## 复杂度

- 时间 O(n)：两种都是常数趟遍历。
- 空间 O(n)（哈希）；穿插法 O(1)。

## 易错点

- random 可能为 None，每次先判空。
- 拆分时两个链表的 next 都要正确，别只改一边。
- 哈希 key 要稳定，Python 用 id()（节点本身不可哈希时）。
