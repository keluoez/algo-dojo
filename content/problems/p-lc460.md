solution_code: |
  from collections import OrderedDict, defaultdict

  class LFUCache:
      def __init__(self, capacity: int):
          self.capacity = capacity
          self.value_of = {}
          self.freq_of = {}
          self.keys_of_freq = defaultdict(OrderedDict)
          self.min_freq = 0

      def _touch(self, key):
          freq = self.freq_of[key]
          del self.keys_of_freq[freq][key]
          if not self.keys_of_freq[freq]:
              del self.keys_of_freq[freq]
              if freq == self.min_freq:
                  self.min_freq += 1
          self.freq_of[key] = freq + 1
          self.keys_of_freq[freq + 1][key] = None

      def get(self, key: int) -> int:
          if key not in self.value_of:
              return -1
          self._touch(key)
          return self.value_of[key]

      def put(self, key: int, value: int) -> None:
          if self.capacity <= 0:
              return
          if key in self.value_of:
              self.value_of[key] = value
              self._touch(key)
              return
          if len(self.value_of) == self.capacity:
              old_key, _ = self.keys_of_freq[self.min_freq].popitem(last=False)
              del self.value_of[old_key]
              del self.freq_of[old_key]
          self.value_of[key] = value
          self.freq_of[key] = 1
          self.keys_of_freq[1][key] = None
          self.min_freq = 1

设计 LFU（最不经常使用）缓存：

- `get(key)`：存在返回值，否则 -1；
- `put(key, value)`：key 存在则更新；不存在则插入，容量满时淘汰**使用频率最低**的键；频率相同，淘汰其中**最久未使用**的键。

要求两个操作平均 O(1)。

**提示**：需要同时维护"频率"与"频率内部的新旧次序"两层信息；频率桶用什么结构可以 O(1) 弹出桶内最旧键？

--- 题解 ---

## 思路：双哈希 + 频率桶 OrderedDict

- value_of：key → 值；freq_of：key → 频率；
- keys_of_freq[f]：频率 f 上所有键的 OrderedDict，**插入顺序即新旧顺序**，popitem(last=False) O(1) 取最旧；
- min_freq：当前最低频率，淘汰时直接定位该桶。

每次访问（get 或更新命中）执行 `_touch`：把 key 从旧频率桶删掉、加进 f+1 桶；旧桶空了且它正好是 min_freq，min_freq 才 +1。插入新键频率为 1，min_freq 重置为 1。

## 示例关键点追踪

put(4) 前：键 1、3 频率均为 2，但 1 进 f2 桶更早（get1 先于 get3），同频 LRU 淘汰 1，get1=-1。这验证了"频率桶内保序"是必需的，不是可有可无。

## min_freq 为什么不用全局扫描

只有两种改变：新键插入 → 必为 1；min 桶因提升变空 → 恰好 +1（其他桶频率都更高）。两种情况下 min_freq 都能直接推出，这是 O(1) 的核心。

## 复杂度

- get / put 平均 O(1)。
- 空间 O(capacity)。

## 与 LRU 对照

LRU 只排一条时间线；LFU 多一层频率分桶、桶内再排时间线。LFU 抗"偶尔的历史热点"更强（老热点频率高会赖着不走是其缺点，真实系统如 Redis 用近似 LFU + 频率衰减改进）。

## 易错点

- capacity=0 是合法构造，put 必须直接忽略。
- 桶空后删除 dict 键，否则残留空桶干扰判断。
