solution_code: |
  class TrieNode:
      def __init__(self):
          self.children = {}
          self.is_end = False

  class Trie:
      def __init__(self):
          self.root = TrieNode()

      def insert(self, word):
          node = self.root
          for ch in word:
              node = node.children.setdefault(ch, TrieNode())
          node.is_end = True

      def _walk(self, text):
          node = self.root
          for ch in text:
              if ch not in node.children:
                  return None
              node = node.children[ch]
          return node

      def search(self, word):
          node = self._walk(word)
          return node is not None and node.is_end

      def starts_with(self, prefix):
          return self._walk(prefix) is not None

实现 Trie 类：`insert` 插入单词，`search` 判断完整单词是否存在，`starts_with` 判断是否有单词以给定前缀开头。

**提示**：search 和 starts_with 的唯一区别是什么？为什么需要 is_end 标记？

--- 题解 ---

## 思路：节点 dict + is_end

每个节点持有 `children: 字符→节点` 与 `is_end`。三种操作的前半段都是同一个 `_walk`：沿字符路径走，走不通返回 None。

- starts_with：walk 非 None 即可；
- search：还要确认落点 `is_end`——路径走得通只代表是某个词的前缀（app/apple 的区别）。

插入时路径节点存在则复用（setdefault），走完全程置 is_end。

## 复杂度

- 三个操作均 O(L)，L 为词长，与词库大小无关。
- 空间 O(所有词总字符数)，共享前缀部分只存一份。

## 易错点

- 忘判 is_end 会把前缀误当单词。
- 插入走已有字符不要新建节点，否则共享结构被破坏。
