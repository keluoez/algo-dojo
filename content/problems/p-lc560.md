  def subarray_sum(nums, k):
      counts = {0: 1}              # 前缀和 -> 出现次数；初始放 0
      prefix = 0
      answer = 0
      for x in nums:
          prefix += x
          answer += counts.get(prefix - k, 0)
          counts[prefix] = counts.get(prefix, 0) + 1
      return answer

给定整数数组（**元素可能为负**）和整数 `k`，统计并返回数组中和为 `k` 的**连续子数组**个数。

**提示**：滑动窗口在含负数时为什么会失效？把数组转成前缀和后，问题变成什么形式？

--- 题解 ---

## 思路：前缀和 + 哈希计数

设当前前缀和为 `p = nums[0]+...+nums[i]`。一个以 i 结尾、和为 k 的子数组，等价于存在更早位置的前缀和等于 `p - k`。

所以维护哈希 `counts`：每个历史前缀和出现了几次：

1. 初始必须放 `{0: 1}`——代表"空前缀"，否则从下标 0 开始的子数组被漏掉；
2. 每步累加前缀和，把 `counts[p-k]` 加进答案；
3. 再记录当前前缀和出现次数 +1。

为什么不能滑窗：有负数时，窗口扩缩与窗口和不再单调，无法用窗口边界判定。

## 复杂度

- 时间 O(n)：一趟扫描。
- 空间 O(n)：哈希表存前缀和。

## 易错点

- 哈希初始 `{0:1}` 不能少。
- 是**计数**问题：同前缀和可能出现多次，value 存次数而非下标。
- 先更新答案再更新哈希，顺序不能反。
