  from collections import deque

  def max_sliding_window(nums, k):
      dq = deque()       # 存下标，对应值递减；队头即窗口最大值
      answer = []
      for i, x in enumerate(nums):
          while dq and nums[dq[-1]] <= x:
              dq.pop()                  # 新元素淘汰队尾更小者
          dq.append(i)
          if dq[0] <= i - k:
              dq.popleft()              # 队头过期
          if i >= k - 1:
              answer.append(nums[dq[0]])
      return answer

整数数组 nums，窗口大小 k 从最左滑到最右，每次只移动一位。返回每个窗口的最大值。

**提示**：朴素每窗口求最大 O(nk)。候选最大值用什么结构维护，能做到每个元素只进出一次？

--- 题解 ---

## 思路：单调双端队列

维护 deque 存下标，对应的值**递减**，队头始终是当前窗口最大值。每轮做三件事：

1. 新元素 x 入队前，队尾所有比 x 小（≤）的下标弹出——它们在 x 之后不可能成为最大值；
2. 队头下标若已滑出窗口（`≤ i-k`），popleft；
3. 从第 k-1 轮开始收集队头对应值。

## 复杂度

- 时间 O(n)：每个下标至多进出队一次。
- 空间 O(k)：deque 不超过窗口长度。

## 易错点

- 两件清理别漏：队尾淘汰更小、队头清理过期。
- 比较符号 `<=`：相等值也要淘汰旧的（新下标活得更久）。
- 第一个答案在 `i == k-1` 时产生，不是 0。
