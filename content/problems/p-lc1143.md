  def longest_common_subsequence(text1: str, text2: str) -> int:
      m, n = len(text1), len(text2)
      dp = [[0] * (n + 1) for _ in range(m + 1)]
      for i in range(1, m + 1):
          for j in range(1, n + 1):
              if text1[i - 1] == text2[j - 1]:
                  dp[i][j] = dp[i - 1][j - 1] + 1
              else:
                  dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
      return dp[m][n]

给定两个字符串 `text1` 和 `text2`，返回这两个字符串的**最长公共子序列**的长度（子序列不连续、保序）；不存在返回 0。

**提示**：二维表格 dp[i][j] 表示什么？两个串的末尾字符相等时答案从哪个格子来？不相等时为什么是"上方"和"左方"取 max，而不是"左上"？

--- 题解 ---

## 思路：二维 DP

dp[i][j] = text1 前 i 个字符与 text2 前 j 个字符的 LCS 长度：

- 末尾字符相等（text1[i-1]==text2[j-1]）：它俩配对必然最优，`dp[i][j] = dp[i-1][j-1] + 1`；
- 不相等：至少一个末尾字符不在公共序列里，丢弃 text1 末位或 text2 末位，取 `max(dp[i-1][j], dp[i-1][j])`。

注意不相等时**不看左上 + 任何东西**：左上代表同时丢两个末位，必然不优于只丢一个，是上/左结果的子集。

第 0 行、第 0 列全 0（空串与任何串 LCS 为 0）。

## 复杂度

- 时间 O(m·n)，空间 O(m·n)，可用滚动行压缩到 O(n)。

## 子序列 DP 的通用骨架

凡是两个序列/字符串对齐类问题（LCS、编辑距离 LC72、最短公共超串、正则匹配），状态都是"两个前缀"，转移都围绕**末位字符是否配对**展开。

## 易错点

- 下标错位：dp 表多一行一列，访问字符时要 i-1/j-1。
- 相等时必须 +1 且取左上，不相等时绝不能 +1。
