  from collections import deque

  def can_finish(num_courses: int, prerequisites: list[list[int]]) -> bool:
      graph = [[] for _ in range(num_courses)]
      indegree = [0] * num_courses
      for course, prereq in prerequisites:
          graph[prereq].append(course)
          indegree[course] += 1

      queue = deque([i for i in range(num_courses) if indegree[i] == 0])
      taken = 0
      while queue:
          course = queue.popleft()
          taken += 1
          for nxt in graph[course]:
              indegree[nxt] -= 1
              if indegree[nxt] == 0:
                  queue.append(nxt)
      return taken == num_courses

本学期有 `num_courses` 门课，记为 0 到 n-1。`prerequisites[i] = [a, b]` 表示要先修 b 才能选 a。判断是否**可能完成所有课程的学习**。

**提示**：依赖关系是一个有向图；有环（A 依赖 B、B 依赖 A）则死锁无解。什么样的顶点可以最先被安全选修？

--- 题解 ---

## 思路：Kahn 拓扑排序（入度剥离）

1. 建邻接表（先修 → 后续课），统计每门课入度（还差几门先修）；
2. 入度为 0 的课进队列——它们没有前置要求，可以立刻上；
3. 取出一门课，把它指向的课入度 -1，减到 0 就入队；
4. 最终被取出的课数等于总课数 → 无环、可完成。

环上的课入度永远降不到 0，会被剩下，所以 taken < n。

## 另一种解法：DFS 染色

DFS 中用 0/1/2 标记未访问、在当前递归栈、已处理完；遇到"在栈中"的邻居即有回边 = 有环。Kahn 写法非递归、且顺带给出合法顺序（LC210 直接复用），通常更推荐。

## 复杂度

- 时间 O(V+E)，空间 O(V+E)。

## 现实对应

课程安排、Makefile 构建顺序、软件包依赖安装（apt/pip 的依赖解析）、任务流水线调度，本质都是"有向图无环 + 拓扑序"。

## 易错点

- 边的方向别建反：b 是 a 的前置，graph[b].append(a)。
- 初始入队的是所有入度 0 的点，不能只取一个。
