solution_code: |
  def min_sub_array_len(target: int, nums: list[int]) -> int:
      total = sum(nums)
      if total < target:
          return 0
      left = 0
      window = 0
      best = len(nums) + 1
      for right, num in enumerate(nums):
          window += num
          while window >= target:
              best = min(best, right - left + 1)
              window -= nums[left]
              left += 1
      return 0 if best == len(nums) + 1 else best

给定一个含有 **n 个正整数**的数组和正整数 `target`，找出满足子数组元素和 `>= target` 的**最短连续子数组**长度；不存在返回 0。

**提示**：所有数都是正数这一条件为什么关键？窗口和一旦达标，左端可以做什么？

--- 题解 ---

## 思路：正整数上的滑动窗口

因为元素均为正，窗口和对"右扩"单调增、对"左缩"单调减，于是：

1. 右端逐个加入，累加 window；
2. 只要 window >= target，就不断从左端删除并更新最短长度——删到不达标为止，因为再留着左端只会更长。

开头一次 `sum(nums) < target` 的快速返回是可选优化，能省掉 best 哨兵的最终判断之外的边界讨论。

## 复杂度

- 时间 O(n)：每个元素进窗、出窗各一次。
- 空间 O(1)。

## 扩展

若允许负数，单调性失效，滑动窗口不再适用，应改用"前缀和 + 单调队列/二分"。这正说明滑动窗口的适用前提是**扩张与收缩的单调性**。
